# Adeng-Adeng Bungalows & Beach Bar Website

A complete, production-ready website for **Adeng-Adeng Bungalows & Beach Bar** on Gili Meno island, Indonesia.

## 🌴 About

Adeng-Adeng is a beachfront beach bar, restaurant, and bungalow accommodation located on the west coast of Gili Meno, directly next to the famous Turtle Sanctuary — literally the best spot in Indonesia to swim with wild sea turtles.

## 🚀 Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/USERNAME/adeng-adeng.git
cd adeng-adeng
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

3. Visit `http://localhost:8000` in your browser

### Deployment to Netlify

1. **Push to GitHub:**
```bash
git init
git add .
git commit -m "Initial commit: Adeng-Adeng website"
git remote add origin https://github.com/USERNAME/adeng-adeng.git
git push -u origin main
```

2. **Connect to Netlify:**
   - Go to [Netlify](https://www.netlify.com/)
   - Click "New site from Git"
   - Connect your GitHub repository
   - Set publish directory to `/` (root)
   - Deploy!

3. **Custom Domain:**
   - Add `adeng-adeng.com` in Netlify dashboard
   - Update DNS records as instructed
   - Enable HTTPS (automatic)

## 📸 Image Requirements

### Image Naming Convention
- `turtles-*.jpg` → Turtle/marine life images
- `snorkeling-*.jpg` → Snorkeling activity images  
- `horse-tours-*.jpg` → Cidomo and horse images
- `beach-bar-*.jpg` → Beach bar and restaurant images
- `bungalows-*.jpg` → Accommodation images
- `adeng-adeng-logo.*` → Logo files (svg preferred, png fallback)
- `diving-*.jpg` → Underwater/diving images
- `food-*.jpg` → Food and cuisine images
- `culture-*.jpg` → Local culture images
- `sunset-*.jpg` → Sunset images
- `beach-*.jpg` → Beach scenery

### Image Processing
All images should be:
- **Card images:** 800x600px (4:3 ratio)
- **Hero images:** 1920x1080px minimum (16:9 ratio)
- **Gallery images:** 800x800px (1:1 ratio)
- **Optimized:** WebP format with JPG fallback
- **Lazy loaded:** Using native `loading="lazy"` attribute
